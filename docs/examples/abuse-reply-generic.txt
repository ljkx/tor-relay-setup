- Spam or abusive posts: rate limits, CAPTCHAs or moderation for new
  accounts, and spam filters on content rather than on addresses.
- Login or SSH brute force: rate limiting (fail2ban or similar), strong
  passwords or keys, and two-factor authentication.
- Scanning or exploitation attempts: keeping the software up to date and
  monitoring the service; these requests also arrive from many non-Tor
  addresses.
- Scraping or denial of service: request rate limits and caching at the web
  server or a reverse proxy.

If you still prefer to treat Tor traffic differently, the Tor Project
publishes the current list of exit addresses, which you can use to block or
flag requests from Tor:
