You are probably reading this because you saw a connection from this address in your logs. This server, {{.Nickname}}, is a relay of the Tor network, run by a volunteer. The traffic you saw did not start here: it was relayed on behalf of a Tor user.

What Tor is

Tor is free software and an open network that helps people keep their browsing private. Each connection passes through three relays chosen at random, and this exit relay is the last one: it only sees where the traffic goes, never who sent it. Journalists, activists, people in censored countries, companies, law enforcement and ordinary people use Tor every day to protect themselves.

What the operator can and cannot do

  • This relay keeps no logs of the traffic it forwards. There is no way to tell which Tor user made a particular connection, so seizing or inspecting this server would not reveal it either.
  • The operator can only block destination addresses and ports for all users at once. The exit policy of this relay is public and listed in Tor Metrics.
  • You can check whether an address was a Tor exit at a given time with ExoneraTor.

If you want to block Tor

Most problems are better solved by fixing the service itself (rate limits, CAPTCHAs, patching), because the same behaviour comes from the rest of the Internet too. If you still want to block Tor exits, the Tor Project publishes a list of current exit addresses: check.torproject.org/torbulkexitlist.

Legal background

Relay operators forward traffic without selecting or changing it, much like an Internet service provider. The Electronic Frontier Foundation's Legal FAQ for Tor Relay Operators explains the situation in the United States; the law where this server runs may differ.
